# Demo Notes

A small demo repository used to test the **Gantry** Android client.

## Features
- Create and edit notes
- Dark mode
- Offline sync

## Quick start
```bash
git clone https://github.com/gantry-demo/demo-notes.git
cd demo-notes
./run.sh
```
